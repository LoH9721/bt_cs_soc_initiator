# CR009 手机 PEPS 自动解闭锁 使用说明

版本：2026-08-20（对应提交 `9233acc`）

本文说明手机无感钥匙（PEPS）自动解锁/自动闭锁的功能定位、如何开启与配置、正常使用流程、边界行为，以及用于验收的判定标准。适用于测试分析、售后说明和二次开发参考。

## 1. 功能概览

手机钥匙在授权蓝牙链路下，依据手机与车辆的估计距离自动解闭锁：

- 自动解锁：人走近车辆（约 3~8.5m，随灵敏度档位），车辆自动解锁；
- 连接状态自动闭锁：人开门上下车后走远（约 15m），车辆自动闭锁一次，需"门资格"；
- 断连闭锁兜底：蓝牙断开后，仅当断开前人在远区，5s 后自动闭锁；
- 静默/门开防护：安全失败静默期或门/尾门开着时，禁止自动解闭锁。

## 2. 如何开启与配置

### 2.1 走近灵敏度档位

协议 0x65 设置（EEPROM 持久化，三档）：

| 档位 | 走近解锁距离 | 适用 |
|---|---|---|
| 近（默认 300cm） | 约 3m 才解锁 | 环境干扰大、希望更晚解锁 |
| 标准（默认 700cm） | 约 7m 解锁 | 常规 |
| 远（默认 850cm） | 约 8.5m 解锁 | 希望更早解锁 |

档位只影响"走近解锁"距离；走远闭锁边界固定约 10m/15m，不受档位影响。

### 2.2 自动解锁额度

蓝牙自动解锁默认 5 次额度，每次自动解锁扣 1（不论成败、不返还）；额度=0 后自动解锁被禁止，可通过协议 0x66 重置。额度不影响任何闭锁路径。

### 2.3 距离/区域阈值

6 个区域阈值可通过串口标定并 EEPROM 持久化，默认值见 `user_app_fun/user_app_phone_peps.h`（走近/走远边界约 1.5/6/10/15m）。

## 3. 正常使用流程

### 3.1 走近解锁

```text
持手机走近（进入闭锁区/无效区后，跨过灵敏度边界）
→ 车辆 LOCKED 且非静默、额度>0
→ 车辆自动解锁（一次）
```

### 3.2 上车 / 下车

解锁后开门上车（或开门下车），关门。此"任一门开到所有门关闭"动作建立离车闭锁资格。

### 3.3 走远闭锁

```text
带手机走远超过约 15m（进入无效区）
→ 持有门资格 + 非静默 + 门全关
→ 车辆自动闭锁一次
```

### 3.4 蓝牙断连兜底

若走远过程未完成闭锁（如距离估计偏差、命令未生效），蓝牙最终断开且断开前人在远区，断开 5s 后自动闭锁。

## 4. 边界行为（重要）

| 情况 | 行为 |
|---|---|
| 没开过门就直接走远 | 不自动闭锁（无门资格）；蓝牙断开后由 005 兜底 |
| 走远到一半又走回来（回到约 7m 内）再走远 | 资格撤销，第二次不区域闭锁；最终靠断连兜底 |
| 门/尾门开着走远或断连 | 不闭锁（防夹），这是故意行为 |
| 静默期（连续 3 次安全失败，60s） | 自动解闭锁全部禁止 |
| 车旁蓝牙闪断 5s | 不闭锁（断开前在近区，无远区证据） |
| 已闭锁后再走远 | 不重复闭锁 |
| 手动/射频钥匙/APP 改变锁状态 | BG24 尊重最终锁状态，不与用户操作对打 |
| 人在 10~15m 之间停留 | 不闭锁（阈值设计，未到 15m 无效区） |
| 首次连接时人已在远区 | 不闭锁（无"由近走远"过程，无门资格） |

## 5. 使用限制与注意事项

- 距离是 RSSI 估计，不同手机射频差异会导致实际闭锁距离偏移（10~15m 之间波动），弱信号可能提前、强信号可能偏晚；断连兜底保证最终落锁。
- 只读 0x282 锁状态，不识别锁动作来源；与射频钥匙共存时由 VIU 做最终仲裁。
- 无 P 挡/IGN 要求：自动闭锁不要求熄火，自动解锁不要求门全关。
- 当前仅一把手机钥匙场景；多钥匙/实体钥匙共存需 VIU 侧决策。

## 6. 测试场景与判定规范

### 6.1 区域与距离模型（默认阈值）

| 区域 | 进入条件（走近） | 离开条件（走远） |
|---|---|---|
| 车内 IN_CAR | 解锁区 ≤ 150cm | 解锁区 > 600cm |
| 解锁区 OUTSIDE_UNLOCK | 闭锁区 ≤ 灵敏度档位 | 车内 > 600cm / 闭锁区 > 1000cm |
| 闭锁区 OUTSIDE_LOCK | 无效区 ≤ 1200cm | 解锁区 > 1000cm |
| 无效区 PARKING_INVALID | 闭锁区 > 1500cm | — |

通用防抖：区域连续 5 次采样确认（约 1.5s）；自动命令后 2s 冷却；命令只在区域确认切换时触发一次。

### 6.2 测试矩阵（按优先级）

| # | 场景 | 前置 | 操作 | 预期 | 日志关键字 |
|---|---|---|---|---|---|
| T1 | 自动解锁 | 授权 L4、LOCKED、额度>0 | 从 15m 外走近到 5m | 1 次 UNLOCK，车解锁，额度-1 | `AUTO UNLOCK (cooldown` |
| T2 | 已解锁走近 | UNLOCKED | 走近 | 不解锁 | `AUTO UNLOCK skipped: already unlocked` |
| T3 | 静默期 | 触发 3 次安全失败 | 走近/走远/断连 | 无自动动作 | `silent` |
| T4 | 004 门资格闭锁 | UNLOCKED、门开→关 | 走远到 16m | 1 次 LOCK，车闭锁 | `leave-lock qualified` + `AUTO LOCK (cooldown` |
| T5 | 004 无资格 | UNLOCKED、门从未开 | 走远到 16m | 不区域闭锁 | `no leave-lock qualify` |
| T6 | 004 门开 | UNLOCKED、任一门开 | 走远到 16m | 不闭锁（004+005 都不动） | `door open` |
| T7 | 004 中途折回 | 有资格 | 走远到 12m 折回 7m 再走远 16m | 第二次不区域闭锁 | `no leave-lock qualify` |
| T8 | 005 走远断连 | 远区、UNLOCKED、门关 | 走远断开 5s | 1 次 LOCK | `disconnect timer start` + `AUTO LOCK (authorized link disconnected` |
| T9 | 005 车旁闪断 | 近区、UNLOCKED | 车旁断开 5s | 不闭锁 | `need far zone before drop` |
| T10 | 005 重连取消 | 远区断开 <5s | 5s 内重连 | 不闭锁 | `reconnect → lock timer cancel` |
| T11 | 额度=0 | 自动解锁 5 次耗尽 | 走近 | 不解锁 | `quota exhausted` |
| T12 | 闭锁后循环 | 完成 T1+T4 | 走近解锁→开门→关门→走远 | 每次循环正常解/闭锁一次 | 见 T1/T4 |

### 6.3 回归项

- 未授权连接：不输出有效区域、不自动解锁；距离超过 1500ms 无新样本（STALE）不动作。
- 授权断开闭锁：断开 5s 闭锁、5s 内重连取消、未授权/L1/Passive OFF 断开不闭锁。
- 既有通过项回归：静默、门/尾门门控、额度只约束自动解锁。
